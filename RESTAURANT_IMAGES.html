ການດຶງຮ້ານ ແລະ ຮູບຮ້ານ POS v1 + v2

API ດຽວດຶງຮ້ານຈາກ DB ທັງສອງເວີຊັນ. ຮູບຮ້ານຢູ່ຄົນລະ S3 bucket: v1 ເກັບແຕ່ຊື່ໄຟລ໌ ຕ້ອງຕໍ່ base URL ເອງ, v2 ເກັບເປັນ URL ເຕັມແລ້ວ.

Endpoint ດຶງຮ້ານ

  • GET /api/v1/subscription/restaurants: ລາຍການຮ້ານ v1 + v2 ລວມກັນ. ແຕ່ລະແຖວມີ posVersion ແລະ logo
  • Query: posVersion=v1|v2|both, search, province, limit (ຄ່າເລີ່ມຕົ້ນ 50), skip
  • GET /api/v1/subscription/restaurants/:id/:posVersion: ລາຍລະອຽດຮ້ານດຽວ
  • GET /api/v1/support/restaurants/search?q=: ຄົ້ນຫາແບບສັ້ນ, ສົ່ງ logo ກັບມາດ້ວຍ

POS v1: appzapimglailaolab

  • Field: image (API ສົ່ງຄ່າດຽວກັນມາໃນ logo ນຳ)
  • ເກັບແຕ່ຊື່ໄຟລ໌, ເຊັ່ນ fb20180f-….jpeg
  • ຮູບເຕັມ: https://appzapimglailaolab.s3.ap-southeast-1.amazonaws.com/<image>
  • ຮູບຫຍໍ້: …/resized/small/<image> ຫຼື …/resized/medium/<image>

POS v2: appzap-v2-restaurant-menu-images

  • Field: logo ເປັນ URL ເຕັມແລ້ວ, ໃຊ້ໄດ້ເລີຍ
  • Base: https://appzap-v2-restaurant-menu-images.s3.ap-southeast-1.amazonaws.com
  • coverImage ແລະ galleryImages ມີໃນ DB ແຕ່ API ຍັງບໍ່ສົ່ງມາ
  • ຮູບແບບ URL ເຕັມຂອງ v2 ຢືນຢັນຈາກໂຄດເທົ່ານັ້ນ, ຍັງບໍ່ໄດ້ query DB ເບິ່ງ

ຕົວຢ່າງການຕໍ່ URL ຮູບທາງ client

const V1_IMG = "https://appzapimglailaolab.s3.ap-southeast-1.amazonaws.com";

const imageUrl = (r) => {
  const img = r.logo || r.image;
  if (!img) return null;
  if (img.startsWith("http")) return img;   // v2, or a v1 value that is already a URL
  return `${V1_IMG}/${img}`;                // v1 filename
};
